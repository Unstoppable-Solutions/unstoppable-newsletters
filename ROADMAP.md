# Unstoppable Newsletters — Development Roadmap

This roadmap outlines planned features, improvements, and development priorities for the Unstoppable Newsletters WordPress plugin.

## Immediate Priorities

### 1. WordPress 7.1.3 Compatibility Verification
- **Description:** Verify and update compatibility with WordPress 7.1.3
- **Benefit:** Ensures plugin works with latest WordPress security updates
- **Priority:** High
- **Complexity:** Small
- **Milestone:** v1.6.16
- **Status:** Planned
- **Source:** Code Review

### 2. GitHub-to-SVN Deployment Testing
- **Description:** Validate the automated GitHub Actions workflow for WordPress.org SVN deployment
- **Benefit:** Enables seamless releases without manual SVN management
- **Priority:** High
- **Complexity:** Small
- **Milestone:** v1.6.16
- **Status:** Planned
- **Source:** Code Review

### 3. Documentation Updates
- **Description:** Sync CHANGELOG.md, update README.md, maintain CLAUDE.md
- **Benefit:** Better developer experience and contribution guidelines
- **Priority:** High
- **Complexity:** Small
- **Milestone:** v1.6.16
- **Status:** In Progress
- **Source:** Code Review
